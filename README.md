# Mobile_Sales_Dashboard
📊 Mobile Sales Dashboard

This project provides a comprehensive Mobile Sales Dashboard built to visualize and analyze sales data for various mobile brands and models across India. The dashboard uses key visual indicators to reflect performance metrics, trends, and customer behaviors.
